Annexe A — Installation pas à pas

A.1 Python

Téléchargez Python 3.12 ou 3.13 depuis https://www.python.org/downloads/.

  • Windows : cochez « Add python.exe to PATH » dans le premier écran de l’installateur. Vérifiez ensuite dans PowerShell : py --version.
  • macOS : installez le paquet .pkg, puis double-cliquez Install Certificates.command dans Applications/Python 3.x. Vérifiez dans le Terminal : python3 --version.

A.2 VS Code

Téléchargez Visual Studio Code (https://code.visualstudio.com/), puis installez les extensions Python et Jupyter (Microsoft) depuis l’onglet Extensions.

A.3 Le dossier du cours et l’environnement virtuel

Téléchargez le dossier du cours depuis https://github.com/warint/MNGT60439 (Code → Download ZIP), ouvrez-le dans VS Code (Fichier → Ouvrir le dossier), puis un terminal (Terminal → Nouveau terminal) :

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
# Windows
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Puis Ctrl/Cmd + Maj + P → Python: Select Interpreter → l’interpréteur de .venv.
