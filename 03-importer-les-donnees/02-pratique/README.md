**À remettre** (équipe de deux, ZoneCours, avant minuit) : `sorties/dossier_tesla/` avec les CSV,
`PROVENANCE.md`, `NOTE.md` (150 mots) et le script complété.

**Ce qui fait perdre des points :** une clé ou un courriel écrit dans le script ; un import à une
seule colonne ; un chiffre sans source ; un manquant traité comme un zéro ; un script qui ne
s'exécute pas de haut en bas.
